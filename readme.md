# How to Run Both Projects

## Prerequisites
- Node.js and npm installed on your system

## Setup Instructions

### Project 1
1. Navigate to the first project folder:
    ```bash
    cd social-feed-app
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the development server:
    ```bash
    npm run dev
    ```

### Project 2
1. Open a new terminal and navigate to the second project folder:
    ```bash
    cd movie-explorer
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the development server:
    ```bash
    npm run dev
    ```

Both projects will run simultaneously on different ports (typically `localhost:3000` and `localhost:3001`).
